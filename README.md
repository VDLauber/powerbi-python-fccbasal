📊 Harris-Benedict Dashboard | Python + Power BI

This project simulates a fictional population dataset to build a Power BI dashboard based on the Harris-Benedict BMR formula.

🐍 Data Generation (Python)

Pandas → Data structuring and Excel export

Faker → Random fictional names

Random → Age, gender, weight, and height generation

All individuals in this dataset are completely fictional.

📊 Power BI Process

Data imported from Excel

Cleaning and transformation performed in Power Query

Harris-Benedict formula applied for BMR calculation

Interactive dashboard created for analysis
